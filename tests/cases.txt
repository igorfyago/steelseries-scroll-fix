# Filter cases. One case is four lines:
#   case:   name
#   config: click=0|1  bounce=ms (all buttons)  bounceL/R/M/X1/X2=ms
#           hold=ms (all buttons, 0 is off)  holdL/R/M/X1/X2=ms
#           wheel=0|1  reverse=ms  confirm=ms  first=ms (0 is off)  flip=0|1  resend=0|1
#           blip=ms (press bounce window, 0 is off)
#           (first, flip and blip are off and resend is on unless a case names them)
#   in:     what the mouse sent       "<ms> <L|R|M|X1|X2> <down|up>"  or  "<ms> wheel <+N|-N>"
#   out:    what applications get     same notation, with the time each event is delivered
# An event the filter sends itself is listed at the time it is sent. When it is
# sent because of an incoming event, it comes right after that event. Two wheel
# ticks delivered at the same instant are compared as a pair, in either order.
# Also allowed in "in":
#   "<ms> ... inj"         the event was injected by another program: never judged
#   "<ms> hwheel <+N|-N>"  the sideways wheel: never judged
#   "<ms> off" / "<ms> on" the guard is switched off or back on
